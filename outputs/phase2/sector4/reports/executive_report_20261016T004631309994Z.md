# Phase 2 — Sector 4: Frame Splits and Domain Adaptation

This sector partitions unique accepted labelled frames into reproducible train, validation, and test sets. All annotations of one decoded frame share its split. Every class has the configured minimum frame support in every split; the same video may occur in several splits.

The frame manifest contains **47,229 unique frames** from **43 labelled videos**. The video manifest contains **129 video/split memberships**, not distinct videos. The adaptation manifest contains **185,755 unlabelled frame references**.

Every video with validation or test frames is excluded from adaptation, including mixed-membership videos. Eligible train-only videos must have no rejected source annotations; all accepted labelled frames are excluded from sampling. Fully unlabelled videos remain eligible when enabled. Unlabelled frames are not assumed to be clinically normal. No frames are decoded or exported here.

Evaluation concerns new frames from shared source videos; temporal similarity may inflate measured performance. Downstream consumers must join by (video_key, opencv_frame_index) and preserve frame splits in segments and temporal context.

Results have stable filenames. Configuration and provenance snapshots and report versions are created when their content changes.
