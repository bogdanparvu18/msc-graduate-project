## MSc Project Title: Grounded Multimodal VQA for Network Control-Plane Incident Diagnosis over Dashboards, Topology Views, and Telemetry
================================================================================================================================================
## Executive summary of the project 
1. start from existing chart/dashboard VQA knowledge,
